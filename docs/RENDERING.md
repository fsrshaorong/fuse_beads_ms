# 柔光玩具房渲染

目标来自[指定参考页](https://soft-toy-room-doucechen-0720.eaudoucefish.chatgpt.site/)，对应 2026-09-07 发布的 `ToyRoomScene-CuoAGneb.js`。保留原站静态笔触、明影染色和纸感，关闭几何及纹理随时间抖动。

## 渲染路径

1. Three.js r185 `MeshStandardMaterial.onBeforeCompile`：UV 采样原笔触，在 `map_fragment` 调制底色。
2. 实时阴影 `getShadowMask()` 与阈值、软硬度形成明影遮罩。
3. 原世界坐标三平面贴图公式生成明面、阴影两种颜色，完整替换 outgoingLight。
4. 按原公式完成降低饱和度、最低黑度与底部染色。
5. Three 的 ACES Filmic（曝光 1.08）与 sRGB 输出各执行一次。

不添加 Bloom、AO、景深、环境图、描边或额外全画面调色。亮色/阴影纹理按原站 sRGB 上传，噪声与三张笔触按数据纹理处理。

## 必要适配

- 顶点变形振幅固定为零，笔触采样时刻固定为零。`update(time)` 不能让材质发生时变，也没有可把抖动重新打开的设置。
- 加入实例矩阵支持，使普通模型和 InstancedMesh 拼豆的世界坐标与阴影正确。数字等功能提示使用单独的无光照材质。
- 保留原站在三平面取样处使用的视空间法线运算，避免“修正”为另一种画面。
- 拼豆工作室有不同的几何、布局与连续透视相机；参考玩具房用正交相机。台灯移到本工作室实际灯泡位置。对齐的是渲染管线，不将不同房间的整张截图称为逐像素相同。
- 墙、地基、地毯与玻璃只接收阴影，窗框、窗帘和家具投射阴影，与原站一致。原静态窗光平面保留颜色、透明度和尺寸，适配当前左窗位置；人物闲置摆头也已关闭。

## 验收

`npm run selfcheck:rendering` 独立启动临时 Vite 和隔离 Chrome，获取原站截图与原始 GLSL，在固定几何、相机下做像素对照，检查跨时间稳定性、普通与实例网格、WebGL 错误。首次运行需联网，缓存后可追加 `-- --offline`。证据输出到 `artifacts/rendering/`。

`npm run selfcheck` 验证完整世界→桌面→拼豆→熨烫→恢复→收藏，并输出各阶段截图。美术验收同时查看总览与近景。

2026-09-07 本机 Chrome 152 验证：固定盒体和地面的原始 GLSL 对照为 0 像素差；9 类材质在 0→0.6 秒之间均 0 像素变化。普通模型与实例模型的平移、旋转、非均匀缩放对照均通过。实例顶点色路径允许最多 1/255、0.01% 像素的浮点插值舍入；实际只有 metal 角色的 1 个像素相差 1 级，其余相同，原 GLSL 和时间稳定性对照仍要求严格零差异。

生产版完整玩法自检通过，含静止工作室截图逐字节一致、美术滑块生效和重置还原画面；本地控制台/WebGL 错误为零。1280×720、DPR 1 的本机样本帧间隔 P50/P95 约 16.7 ms，156 draw calls、约 45 万三角形（含阴影 pass）。这不代表其他 GPU 的性能。
